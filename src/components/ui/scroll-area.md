# 🧳 Scroll Area Component

The Scroll Area component provides an accessible and customizable scrollable container for your web application. It utilizes Radix UI for accessibility and Tailwind CSS for responsive and flexible styling. The component also supports smooth animations and can be customized with className and other Tailwind utilities.

---

## 🚀 Features

- 🎯 **Accessible by default** (Radix UI)
- 🎨 **Fully customizable** with Tailwind CSS
- 📦 **Modular components** (`ScrollArea`, `ScrollBar`)
- 🔁 **Smooth scrolling experience** with customizable scrollbar styles
- 📐 **Vertical and Horizontal scroll orientations**
- 🧰 **Utility-based class merging** with `cn()`

---

## 🛠 Tech Stack

- ⚛️ **React**
- 🧳 **Radix UI Scroll Area**
- 💅 **Tailwind CSS**
- 📦 **Lucide React** (optional for icons)
- 🧰 **Utility-based class merging** with `cn()`
