# Resizable Panels Component

This is a **Resizable Panels** component built using **React Resizable Panels** and **Lucide React Icons**. It allows the creation of flexible, resizable panels inside a container, providing a great way to create dynamic layouts where users can resize sections.

## Overview

The **Resizable Panels** component consists of three main subcomponents:
- **ResizablePanelGroup**: A container for the resizable panels, which controls the layout direction (horizontal or vertical).
- **ResizablePanel**: Individual panels that can be resized.
- **ResizableHandle**: A draggable handle that enables users to resize the panels.

This component can be used to create layouts such as sidebars, split screens, or any layout that requires resizable sections.
