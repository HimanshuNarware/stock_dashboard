# 🖱️ Context Menu Component

This file provides an explanation of the functions in the Context Menu component, created using `@radix-ui/react-context-menu` and enhanced with custom styles and behavior. The context menu allows the user to interact with a menu via right-click (or similar action), showing options relevant to their current context.

---

## 🚀 Features

- ✅ Radix UI primitives for accessibility and keyboard support
- 🌈 Customizable with Tailwind CSS
- 📦 Support for:
  - Submenus
  - Checkbox & Radio items
  - Keyboard shortcuts
  - Labels, separators, and groups
- 🎯 Fully typed with TypeScript
- 🎨 Smooth animations and responsive layout
