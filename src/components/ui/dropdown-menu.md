# Dropdown Menu Component

A fully customizable and accessible **Dropdown Menu** component built using [Radix UI](https://www.radix-ui.com/) and styled with **Tailwind CSS**. This component offers an intuitive, flexible dropdown menu for use in any React-based project.

## Features

- ✅ **Built with Radix UI** for accessibility and ease of use
- 🌈 **Fully customizable** with **Tailwind CSS**
- 🧑‍💻 **Typed with TypeScript**
- 🎨 **Smooth animations** for menu items
- 🔒 **Fully accessible** with keyboard navigation and screen reader support
