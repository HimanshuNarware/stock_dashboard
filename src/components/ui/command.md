# Command Palette Component

This is a set of custom command palette components built using **React**, **cmdk** (a command palette library), and **Radix UI** for building accessible, interactive command input systems in your application. These components help manage user commands, search functionality, and interaction in a highly customizable and accessible way.

---

## 🚀 Features

- ⚡ Built with `cmdk` (Command K) primitives
- 🔒 Uses Radix UI Dialog for accessibility
- 🧠 Keyboard-first navigation
- 🔍 Integrated search icon
- 🎨 Customizable with Tailwind CSS
- 🧩 Modular structure for flexibility
