# 🔔 Toaster Component
This is a custom React toast notification system built using Radix UI's Toast primitives. It provides a simple and accessible way to display feedback messages such as success alerts, errors, or other real-time notifications.

## 🚀 Features
⚡ Lightweight and fast – Radix UI ensures optimal performance and minimal bundle size.

♿ Accessible and keyboard-navigable – Includes essential accessibility features like screen reader support and keyboard dismissal.

🎨 Easily customizable – Style with Tailwind CSS or your preferred CSS framework.

🧱 Built with Radix UI primitives – Ensures robust, flexible, and composable toast behavior.

🔧 Full control – Includes Provider, Viewport, and composable Toast components for fine-grained customization.
