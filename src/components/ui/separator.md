# 🧩 Separator Component
A minimalistic and accessible Separator UI component built using Radix UI and Tailwind CSS. Perfect for visually dividing sections of content, whether vertically or horizontally.

## 🚀 Features
🎯 Accessible by default with Radix UI

🎨 Customizable orientation (horizontal/vertical)

🖋️ Fully customizable with Tailwind CSS

⚡ Efficient and lightweight with utility-first styling

🧰 Simple API for decoration and orientation control

## 🛠 Tech Stack
⚛️ React

🧩 Radix UI Separator

💅 Tailwind CSS

🧰 Utility-based class merging with cn()

📦 Installation
``` bash
npm install @radix-ui/react-separator
