# 🔽 Collapsible Component

This is a set of custom components built using **React** and **Radix UI's Collapsible** for creating collapsible content sections in your application. These components allow users to toggle the visibility of content with ease, providing an interactive and accessible way to hide or show information.

---

## 🚀 Features

- ⚡ **Lightweight and fast**: Radix UI components are optimized for performance and minimal bundle size.
- ♿️ **Accessible and keyboard-navigable**: Built-in accessibility features ensure your collapsible sections are usable by everyone.
- 🎨 **Easy to style** with Tailwind or any CSS framework: Customize the look and feel with your preferred styling approach.
- 🧱 **Built with Radix UI primitives**: Uses the Radix UI library for robust, accessible, and customizable collapsible behavior.
- 🔧 **Flexible structure** using `Root`, `Trigger`, and `Content` components: Easy-to-use and flexible components that can be combined to create collapsible sections.

---
