# 🧩 Accordion Component

A flexible, accessible, and beautifully animated **Accordion UI component** built using **Radix UI**, **Lucide React**, and **Tailwind CSS**. Perfect for FAQs, toggleable sections, and content organization in modern web apps.

---

## 🚀 Features

- 🎯 Accessible by default (Radix UI)
- 🎨 Fully customizable with Tailwind CSS
- 📦 Modular components (`AccordionItem`, `Trigger`, `Content`)
- 🔁 Animated open/close transitions
- 📐 Icon rotation on toggle using Lucide

---

## 🛠 Tech Stack

- ⚛️ React
- 🧩 Radix UI Accordion
- 💅 Tailwind CSS
- ✨ Lucide React (Chevron Icons)
- 🧰 Utility-based class merging with `cn()`
