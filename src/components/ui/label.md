# 🏷️ Label Component

A customizable **Label** component built using **React**, **Radix UI**, and **Class Variance Authority (CVA)**. This component is used to provide labels for form inputs, enhancing accessibility and usability by ensuring proper label associations with input elements.

---

## 🚀 Features

- 🧑‍💻 **Customizable styling** using `CVA` and **Tailwind CSS**
- ♿️ **Accessible** by default (Radix UI)
- ✨ **Variant-based styling** for easy customization of different states (e.g., disabled, focus)
- 🏷️ **Easy to use** with `className` prop for additional custom styles
- 🎯 Provides a standard **label element** that can be paired with inputs for better user experience

---
