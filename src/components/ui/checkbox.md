# ✅ Checkbox Component

This component is a custom **Checkbox** built using **React** and **Radix UI's Checkbox** primitives, with styling enhancements using **Tailwind CSS**. The Checkbox allows users to select or deselect an option, providing a clear and customizable way to capture boolean values in forms or interactive UIs.

---

## 🚀 Features

- ✅ **Accessible and keyboard-navigable**: Built with **Radix UI** to ensure full accessibility support.
- 🎨 **Easy to style** using **Tailwind CSS**.
- 📦 **Customizable and reusable**: Can be easily integrated into forms and other UI elements.
- 🔒 **Handles checked and unchecked states**: The component provides clear visual feedback when checked or unchecked.
