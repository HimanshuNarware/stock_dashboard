# 📝 Textarea Component
A customizable and accessible textarea input built with React and Tailwind CSS. It follows modern form patterns and integrates smoothly with any design system.

## 🚀 Features
✅ Fully accessible with keyboard navigation

🎨 Styled with Tailwind CSS

🧩 Supports all native <textarea> props

🛡️ Handles disabled, focus, and placeholder states elegantly

## 🛠 Tech Stack
⚛️ React with forwardRef

💅 Tailwind CSS

🧰 Utility class merging via cn()

📦 Installation

```ts
import { cn } from "@/lib/utils";
