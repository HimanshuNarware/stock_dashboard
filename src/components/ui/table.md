# 📊 Table Component
A modular, accessible, and responsive Table UI component built with React and Tailwind CSS. Perfect for data-heavy interfaces like dashboards, admin panels, and CRUD apps.

## 🚀 Features
✅ Fully accessible & semantic HTML structure

🌐 Responsive container with scroll support

🖌️ Styled using Tailwind CSS utility classes

🔁 Modular subcomponents: Table, TableRow, TableHead, TableCell, etc.

✨ Smooth hover & selection states

## 🛠 Tech Stack
⚛️ React (with forwardRef)

💅 Tailwind CSS

🧰 Class merging with cn()
