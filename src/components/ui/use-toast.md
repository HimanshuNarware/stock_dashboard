# 🧑‍💻 useToast Hook
The useToast hook is a custom React hook that allows you to trigger and manage toast notifications in your application. It simplifies the process of showing success, error, or informational messages to users.

This hook works seamlessly with the Toast component created earlier, providing an easy API for adding notifications dynamically.

## 🚀 Features
**Customizable** : Easily customize the messages, appearance, and actions of your toast notifications.

**Control Toasts Dynamically**: Trigger toasts from anywhere in your app with different variants (success, error, info, etc.).

**State Management**: Manages the state of toasts in the application, including displaying and hiding them automatically.

**Actionable**: Optionally provide actions (like close buttons or undo actions) inside the toast notifications.
