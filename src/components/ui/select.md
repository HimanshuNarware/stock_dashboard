# 🧩 Select Component
A flexible, accessible, and beautifully customizable Select UI component built using Radix UI, Lucide React, and Tailwind CSS. Perfect for creating dropdowns, forms, and dynamic content selection in modern web applications.

## 🚀 Features
- 🎯 Accessible by default with Radix UI
- 🎨 Fully customizable with Tailwind CSS
- 📦 Modular components (Select, Trigger, Content, Item, etc.)
- 🔁 Animated open/close transitions
- 📐 Chevron icons for dropdown toggling using Lucide
- 🧑‍💻 Scroll buttons for large select lists

## 🛠 Tech Stack
- ⚛️ React
- 🧩 Radix UI Select
- 💅 Tailwind CSS
- ✨ Lucide React (Chevron Icons, Check)
- 🧰 Utility-based class merging with cn()

## 📦 Installation

npm install @radix-ui/react-select lucide-react
