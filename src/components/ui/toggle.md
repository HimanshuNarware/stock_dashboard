# 🕹️ Toggle Component
A customizable Toggle component built with React and Radix UI's Toggle primitive. Use it to create interactive toggle buttons, switches, or on/off toggles in your application.

## 🚀 Features
⚡ Fast and responsive – Leverages Radix UI's primitives for performance and accessibility.

🎨 Flexible styling – Customizable using utility-first CSS frameworks like Tailwind with class-variance-authority.

🧱 Variant and size support – Easily adjust toggle styles using predefined variants (e.g., outline, default) and sizes (e.g., sm, lg).

♿ Accessibility – Built-in keyboard navigation and screen reader support.

🔄 Toggle states – Includes built-in support for managing on and off states.

## 📦 Installation

npm install @radix-ui/react-toggle
