# 🔐 Input OTP Component

A customizable and accessible **OTP (One-Time Password) Input UI component** built using **React**, **input-otp**, **Lucide Icons**, and **Tailwind CSS**. Ideal for secure login, verification, or 2FA workflows in modern web applications.

---

## 🚀 Features

- 🔢 Supports segmented OTP input
- 🎨 Fully styled with Tailwind CSS
- 🧩 Composed of reusable components: `InputOTP`, `InputOTPGroup`, `InputOTPSlot`, and `InputOTPSeparator`
- 🧠 Keyboard and screen reader accessible
- ✨ Visual caret animation and focus indication
