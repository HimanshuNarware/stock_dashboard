# 🖼️ Aspect Ratio Component

A lightweight wrapper around [Radix UI's Aspect Ratio](https://www.radix-ui.com/primitives/docs/components/aspect-ratio) primitive to maintain consistent media proportions in your layout (e.g., videos, images, iframes).

---

## 🚀 Features

- 🔲 Maintains fixed aspect ratios (e.g., 16:9, 4:3)
- 📐 Perfect for responsive media elements
- 🌐 Built on Radix UI's robust accessibility-friendly primitive
- 🧩 Simple, declarative API

---

## 🛠 Tech Stack

- ⚛️ React
- 🧱 Radix UI Primitives (`@radix-ui/react-aspect-ratio`)
- 📦 ESModule Export
