# ⚠️ AlertDialog Component

A fully accessible and beautifully animated **Alert Dialog** component built using **Radix UI**, **Tailwind CSS**, and **ShadCN UI** conventions. Perfect for confirmation modals, warnings, or critical actions in your app.

---

## 🚀 Features

- 🔒 Accessible and keyboard-navigable by default
- 🎨 Fully styled using Tailwind CSS
- 🧩 Modular components (Header, Footer, Title, Actions)
- 🎬 Smooth entrance and exit animations
- ✨ Integrated with ShadCN’s `buttonVariants()` utility

---

## 🛠 Tech Stack

- ⚛️ React
- 🎛️ Radix UI AlertDialog
- 💨 Tailwind CSS
- 🧩 ShadCN UI (for button styles and structure)
