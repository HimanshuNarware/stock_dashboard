# Progress Component

The **Progress** component is used to display the progress of a task in a visual format, typically represented as a horizontal bar that fills up as progress is made. It is based on **Radix UI** for accessibility and provides a smooth and responsive experience when showing progress updates.

---

## 🚀 Features

- **Progress Bar**: A dynamic, horizontal progress bar that visually represents the completion of a task.
- **Customizable Styles**: Easily customizable using **Tailwind CSS** for different designs.
- **Smooth Transitions**: Animations for smooth transitions of the progress bar as it fills.
- **Responsive**: Fully responsive to different screen sizes and use cases.
- **Accessibility**: Fully accessible with ARIA attributes provided by **Radix UI**.

---

## 📦 Installation

To install and use the **Progress** component, make sure you have **Radix UI** and **Tailwind CSS** set up in your project:

```bash
npm install @radix-ui/react-progress
