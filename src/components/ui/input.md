# 🎨 Input Component

A customizable **Input field** built with **React** and **Tailwind CSS**. This input component is optimized for accessibility, responsiveness, and ease of use. Ideal for form fields like text inputs, search boxes, and other user input areas in modern web apps.

---

## 🚀 Features

- 🖋 **Customizable styles** with Tailwind CSS
- ⚡ **Accessible and responsive** design
- 🔐 **Focus and state handling** for accessibility
- 🧰 Supports different **input types** (text, password, number, etc.)
- 🎯 **Flexible** class management using `cn()` utility
