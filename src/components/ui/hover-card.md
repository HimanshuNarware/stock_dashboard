# 🪄 HoverCard Component

An elegant and accessible **Hover Card UI component** built using **Radix UI's HoverCard primitives**, **React**, and **Tailwind CSS**. Ideal for user previews, tooltips, and quick info panels that appear on hover.

---

## 🚀 Features

- 🧠 Fully accessible with keyboard and screen reader support
- 🌀 Beautiful entry/exit animations using Tailwind utility classes
- 🧱 Composable parts: `HoverCard`, `HoverCardTrigger`, `HoverCardContent`
- 🎨 Styled with Tailwind CSS for easy customization

---
