# Pagination Component

A **Pagination** component designed using **React**, **Tailwind CSS**, and **Lucide Icons**. It allows users to navigate through a paginated interface with intuitive controls like "Previous", "Next", page numbers, and ellipses for skipped pages.

---

## 🚀 Features

- **Pagination Navigation**: Provides easy-to-use "Previous", "Next", and individual page navigation.
- **Active Page Styling**: Automatically highlights the active page link.
- **Ellipsis for Skipped Pages**: Uses ellipses to indicate more pages when the pagination is too large.
- **Accessibility Support**: Proper ARIA attributes to indicate current pages and navigation actions.
- **Customizable**: Tailored to your design with **Tailwind CSS** utility classes.
- **Responsive**: Adapts to different screen sizes and layouts.
- **Lucide Icons Integration**: Uses **ChevronLeft**, **ChevronRight**, and **MoreHorizontal** for smooth and attractive pagination icons.
