# 🔘 Button Component

A flexible and customizable **Button** component built with **React**, **Tailwind CSS**, and **class-variance-authority (CVA)**. This component provides a wide range of style variants and sizes, making it ideal for use in various UI designs such as forms, modals, actions, and navigation.

---

## 🚀 Features

- **Multiple style variants** for different actions and visual appearances.
- **Customizable sizes** for various use cases.
- **Supports icon-based buttons** with an optional `icon` size.
- **AsChild prop** allows the button to render as another component (e.g., `<a>` tag).
- **Utility-first** styling with Tailwind CSS for ease of use and extendability.
- **Powered by class-variance-authority (CVA)** for managing variant logic in a clean, scalable way.
- **Icon Integration**: Includes support for **Lucide Icons**, **Heroicons**, and other icon libraries.

---

## 🛠 Tech Stack

- ⚛️ **React** for component logic.
- 💨 **Tailwind CSS** for utility-first styling.
- 🧠 **class-variance-authority (CVA)** for variant management.
- 🧰 **Slot** from Radix UI for component flexibility.
- 🔑 **Lucide Icons** or **Heroicons** for easily adding icons.

---
