# 🧭 Breadcrumb Component

A flexible and customizable breadcrumb navigation component built with **React**, **Radix UI**, **Tailwind CSS**, and **Lucide Icons**. This component allows you to create breadcrumb trails that are easy to navigate, with options for separators, ellipses, and active/inactive states.

---

## 🚀 Features

- ✨ **Customizable Breadcrumb Structure**: Build breadcrumb trails with links, separators, and current page indicators.
- 🎨 **Tailwind CSS** for utility-first styling.
- 🧩 **Radix UI** components for enhanced accessibility and flexibility.
- 🖼️ **Lucide Icons** for separators and other icons.
- 📦 Fully responsive and flexible for any project.

---

## 🛠 Tech Stack

- ⚛️ **React**
- 💨 **Tailwind CSS**
- 🔲 **Radix UI** (for accessible and customizable components)
- 💡 **Lucide Icons** (for breadcrumb separators and ellipses)
- 🔄 **class-variance-authority (CVA)** for conditional styling and variant management
