# 🔔 Toast Notification Component
An accessible, themeable toast system built using Radix UI, Tailwind CSS, and CVA (Class Variance Authority). It supports swipe gestures, multiple variants, and responsive placement.

## ⚙️ Features
- ✅ Radix-compliant accessible toast notifications

- 🧩 Variant support: default, destructive, and more via cva()

- 🧠 Keyboard-friendly and screen-reader accessible

- 📱 Swipeable on mobile

- 🎨 Fully themeable with Tailwind utility classes

- 🧼 Auto-dismissal, closable UI, and actions

## 🧱 Components
- ToastProvider – Root provider for toast context

- ToastViewport – Where the toasts appear

- Toast – Main notification container

- ToastTitle – Bold header

- ToastDescription – Secondary text

- ToastClose – Dismiss button (uses Lucide’s X)

- ToastAction – Action button for undo, etc.
