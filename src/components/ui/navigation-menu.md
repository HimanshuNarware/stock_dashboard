# 🌐 Navigation Menu Component

A **Navigation Menu** component built using **React**, **Radix UI**, and **Tailwind CSS**. This component provides a flexible and accessible navigation menu system with smooth transitions, ideal for dropdowns and multi-level menus.

---

## 🚀 Features

- **Accessible** by default with **Radix UI** for managing state and accessibility
- **Smooth Animations** for menu transitions (slide-in/out, fade-in/out)
- **Customizable** via **Tailwind CSS** classes and **class-variance-authority (CVA)**
- **Dropdown-style** triggers with support for dynamic content visibility
- **Responsive** behavior for both mobile and desktop views

---

To use the Navigation Menu component, install the necessary dependencies:
