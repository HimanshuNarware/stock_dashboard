# 🎛️ Toggle Group Component
This is a set of composable toggle group components built with React and Radix UI's ToggleGroup primitive. Use it to create groups of toggleable buttons for filters, formatting tools, or any feature where users can toggle one or more items.

## 🚀 Features
⚡ Fast and efficient – Powered by Radix UI primitives for optimal performance.

♿ Accessible by default – Includes keyboard navigation and screen reader support.

🎨 Customizable with Tailwind CSS – Easily style variants and sizes using utility classes and cva.

🧱 Context-aware – Automatically applies variant and size props to child toggle items using React context.

🔁 Supports single or multiple selection – Fully supports Radix’s single or multiple toggle logic.

## 📦 Installation
```bash
npm install @radix-ui/react-toggle-group
