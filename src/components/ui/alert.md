# ⚠️ Alert Component

A flexible and visually appealing **Alert** component built using **React**, **Tailwind CSS**, and **class-variance-authority (CVA)**. Ideal for displaying status messages, warnings, or notifications in your application.

---

## 🚀 Features

- ✅ Supports multiple variants (default, destructive)
- 🧩 Composable structure (Title + Description)
- 🎨 Tailwind CSS styled with utility-first approach
- ⚙️ CVA-based variant handling for easy customization
- ♿ Accessible via `role="alert"`

---

## 🛠 Tech Stack

- ⚛️ React
- 💨 Tailwind CSS
- 🧠 class-variance-authority (CVA)
- 🧩 Utility functions (`cn` from ShadCN style utils)
