# 📅 Calendar Component

A customizable and accessible calendar component built using **React**, **react-day-picker**, **Tailwind CSS**, and **lucide-react** icons. This component allows you to embed a powerful, styled date picker into your application with full control over appearance and behavior.


---

## 🚀 Features

- 📆 Based on `react-day-picker` for full date selection control.
- 🎨 Styled with Tailwind CSS for easy theming.
- ↔️ Customizable navigation with `Lucide Icons`.
- 👀 Supports outside days (from previous/next months).
- 📌 Keyboard accessible and screen-reader friendly.
- 💡 Tailored with utility classes and `buttonVariants` for consistent design.

---
