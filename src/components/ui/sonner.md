# 🔔 Toaster Component
A sleek, theme-aware Toast Notification System using Sonner, designed for modern Next.js applications with full Tailwind CSS customization and dark mode support via next-themes.

## 🚀 Features
🌙 Dark/light/system theme support via next-themes

⚡ Blazing fast toast rendering with Sonner

🎨 Fully themeable using Tailwind CSS utility classes

🧩 Easy integration across your application

🧰 Utility-based class customization for toast, description, actions

## 🛠 Tech Stack
⚛️ React (Next.js)

🌐 next-themes

🔔 Sonner toast library

💅 Tailwind CSS

## 📦 Installation
```bash
npm install sonner next-themes
