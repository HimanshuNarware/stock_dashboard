# 🧩 Sheet Component
A flexible and customizable Sheet UI component built using Radix UI, Lucide React, and Tailwind CSS. Perfect for off-canvas dialogs, modals, or sliding panels in your web applications.

## 🚀 Features
🎯 Accessible by default (Radix UI)

🎨 Customizable slide-in directions (top, bottom, left, right)

📦 Modular components (Sheet, SheetTrigger, SheetClose, SheetContent, etc.)

🔁 Smooth sliding animations with customizable durations

✨ Close button with an icon using Lucide React

💅 Fully customizable with Tailwind CSS

## 🛠 Tech Stack
⚛️ React

🧩 Radix UI Dialog (used as a Sheet)

💅 Tailwind CSS

✨ Lucide React (for icon usage)

🧰 Utility-based class merging with cn()

🧩 Class Variance Authority (cva) for dynamic styling
