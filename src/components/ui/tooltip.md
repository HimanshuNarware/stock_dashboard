# 🧠 Tooltip Component
A customizable Tooltip component built using React and Radix UI's Tooltip primitive. This component is used to provide contextual information when users hover over or focus on an element. The tooltip appears with smooth animations and can be easily customized to fit your design needs.

## 🚀 Features
⚡ Fast and lightweight: Built using Radix UI's Tooltip primitive for a minimal and performant solution.

🎨 Flexible styling: Customize the appearance of your tooltip with utility-first CSS frameworks like Tailwind CSS.

💡 Smooth animations: Tooltips include transition effects that enhance the user experience with fade and zoom-in effects.

♿ Accessible: Supports keyboard and screen reader navigation out of the box.

🔄 Flexible positioning: Control the position of the tooltip with the sideOffset prop.
