# 🧑‍💼 Avatar Component

A reusable and accessible Avatar component built on top of [Radix UI's Avatar primitive](https://www.radix-ui.com/primitives/docs/components/avatar). Ideal for displaying user profile images with graceful fallbacks and customization support.

---

## 🚀 Features

- 🖼️ Supports user image display
- 🔁 Graceful fallback for missing/broken images
- 🧩 Composed using Radix UI's accessible Avatar primitives
- 🎨 Fully styleable with Tailwind and utility classes
- 🔄 Forwarded refs for better control

---

## 🛠 Tech Stack

- ⚛️ React
- 📦 Radix UI (`@radix-ui/react-avatar`)
- 💅 Tailwind CSS
- 🧰 Utility Helpers (`cn` function)
