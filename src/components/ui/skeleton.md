# 🧩 Skeleton Component
A Skeleton UI component built using Tailwind CSS. This component provides a lightweight way to show loading placeholders with animation, making it ideal for creating an engaging user experience while data is being fetched.

## 🚀 Features
- 🔄 Pulse animation for smooth loading effect

- 🎨 Customizable styling with Tailwind CSS

- 🧩 Can be used as a placeholder for images, text, or other content

- ⚙️ Simple API with className support for easy styling

## 🛠 Tech Stack
- 💅 Tailwind CSS

- ⚛️ React

- 🧰 Utility-based class merging with cn()
