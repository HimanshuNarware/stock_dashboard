# 🍽️ Menubar Component

A **Menubar** component built using **React**, **Radix UI**, and **Tailwind CSS**. This component offers a flexible, accessible, and customizable menu bar system for navigation, with support for items, submenus, checkboxes, and radio buttons.

---

## 🚀 Features

- **Accessible** by default with Radix UI's menu system
- **Flexible Styling** using **Tailwind CSS** and **class-variance-authority (CVA)**
- **Submenus** support with trigger and content animations
- **Checkbox and Radio Items** for interactive menus
- **Customizable Menu Items** to fit the needs of your UI

---

## 📦 Installation

Ensure the necessary dependencies are installed:

npm install @radix-ui/react-menubar lucide-react class-variance-authority
