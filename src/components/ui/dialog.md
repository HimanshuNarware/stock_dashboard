# 🗨️ Dialog Component

This is a Dialog component built using **Radix UI**'s `Dialog` primitive and React. A dialog is a modal or pop-up window typically used to capture user inputs, display alerts, or prompt actions. This component provides an easy-to-use, fully customizable modal interface for your app.

---

## 🚀 Features

- ✅ Radix UI for accessibility and keyboard navigation
- 🌈 Fully customizable with Tailwind CSS
- 🧑‍💻 Ideal for use cases like forms, confirmations, and any type of modal interaction
- 🎯 Typed with TypeScript for better developer experience
- 🎨 Smooth animations and transitions
- 🔒 Fully accessible with ARIA roles and focus management
