# 📊 Custom Chart Components

This module provides a set of **custom chart components** built on top of **[Recharts](https://recharts.org/)** and **React**, designed for flexible styling, theming, and improved accessibility using **Tailwind CSS** and **Context API**.

---

## 🚀 Features

- 🎨 Theming support for dark/light mode using CSS variables
- 📦 Context-aware configuration via `ChartContext`
- 💡 Customizable tooltip and legend
- 🧱 Radix-style reusable, modular design
- ⚙️ Utility-first styling via Tailwind classes and helper functions

---
