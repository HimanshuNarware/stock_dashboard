# 🎠 Carousel Component

A highly customizable, responsive, and accessible **carousel component** built using [Embla Carousel](https://www.embla-carousel.com/) and **React** with **Tailwind CSS**. Perfect for image sliders, card carousels, testimonials, and more.

---

## 🚀 Features

- 🔄 Horizontal and vertical orientation support
- 🎯 Keyboard navigation (← →)
- 🧠 Context API for flexible control
- 🎮 External API support (`setApi`)
- 🎨 Fully styled with Tailwind CSS
- ♿️ Accessible with roles, labels, and focus management
- 🔌 Plugin support via `embla-carousel-react`

---
