# 🧩 Slider Component
A highly customizable and accessible Slider UI component built using Radix UI and Tailwind CSS. Perfect for creating interactive sliders in modern web applications, such as volume control, rating systems, and range inputs.

## 🚀 Features
🎯 Accessible by default (Radix UI)

🎨 Fully customizable with Tailwind CSS

🧩 Interactive slider for smooth range input

🎛️ Customizable thumb and track styles

🔁 Responsive design for various screen sizes

## 🛠 Tech Stack
⚛️ React

🧩 Radix UI Slider

💅 Tailwind CSS

🧰 Utility-based class merging with cn()

## 📦 Installation

```bash
npm install @radix-ui/react-slider
