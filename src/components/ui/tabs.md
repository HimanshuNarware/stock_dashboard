# 🗂️ Tabs Component
An elegant, accessible Tabs UI component built with Radix UI, Tailwind CSS, and React. Ideal for content organization in dashboards, forms, modals, and more.

## 🚀 Features
🎯 Built on Radix UI — accessible & keyboard-navigable

🎨 Customizable using Tailwind utility classes

⚡ Fast, animated tab switching

🧩 Composed of modular subcomponents

## 🛠 Tech Stack
⚛️ React with forwardRef

🧱 Radix UI Tabs

💅 Tailwind CSS

🧰 Class merging via cn()

## 📦 Installation

```bash
npm install @radix-ui/react-tabs
