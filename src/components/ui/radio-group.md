## ⚙️ RadioGroup Component
A flexible and visually appealing RadioGroup component built using React, Radix UI, and Lucide Icons. Ideal for creating customizable radio button groups with enhanced styling and accessibility.

## 🚀 Features
- ✅ Customizable radio button styling

- 🧩 Composable structure (RadioGroup + RadioGroupItem)

- 🎨 Tailwind CSS styled with utility-first approach

- ⚙️ Radix UI primitives for accessibility

- 🎨 Lucide Icon used for the radio button indicator

- ♿ Accessible via role="radiogroup"

## 🛠 Tech Stack
- ⚛️ React

- 🧩 Radix UI

- 🔲 Tailwind CSS

- 💎 Lucide Icons

- 🧠 Utility functions (cn from ShadCN style utils)

## 📦 Installation
Install Required Packages
npm install @radix-ui/react-radio-group lucide-react
