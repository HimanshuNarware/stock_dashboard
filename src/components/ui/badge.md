# 🏷️ Badge Component

A customizable badge component built with **React**, **Tailwind CSS**, and **class-variance-authority (CVA)** for handling multiple style variants. Ideal for labeling, status indicators, and compact UI highlights.

---

## 🚀 Features

- ✨ Predefined style variants: `default`, `secondary`, `destructive`, and `outline`
- 🎨 Easily extendable with custom styles
- 💅 Utility-first styling using Tailwind CSS
- 📦 Powered by CVA for scalable variant management
- 🧩 Can be used for tags, status chips, labels, and more

---

## 🛠 Tech Stack

- ⚛️ React
- 💨 Tailwind CSS
- 🧠 class-variance-authority (CVA)
- 🧰 `cn` utility for conditional class merging
