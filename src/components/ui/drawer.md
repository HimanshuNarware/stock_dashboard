# 📦 Drawer Component

This is a Drawer component built using the **Vaul** library and React. The Drawer UI pattern is commonly used for side or bottom panels that slide in to present additional content or options. In this implementation, the component is customized with specific functionality such as triggers, overlays, headers, and footers.

---

## 🚀 Features

- ✅ Built with **Vaul** for accessibility and smooth animations
- 🌈 Fully customizable with **Tailwind CSS**
- 🧑‍💻 Typed with **TypeScript**
- 🎨 Smooth sliding animations from the bottom
- 🔒 Fully accessible with ARIA roles and keyboard navigation
