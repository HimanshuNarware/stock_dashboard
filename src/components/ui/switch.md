# 🔘 Switch Component
An elegant, accessible toggle switch UI component built using Radix UI and Tailwind CSS. Designed for theme toggles, settings toggles, and anywhere you need a clean on/off control.

## 🚀 Features
✅ Built on Radix UI Switch – accessible by default

🌗 Customizable styles with Tailwind CSS

🎨 Smooth animated thumb transitions

🧩 Integrates seamlessly into modern React/Next.js apps

## 🛠 Tech Stack
⚛️ React

🧩 Radix UI Switch

💅 Tailwind CSS

🧰 Utility class merging with cn()

## 📦 Installation
```bash
npm install @radix-ui/react-switch
