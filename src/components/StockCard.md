# StockCard Component

The `StockCard` component displays information about a stock, including its price, change percentage, and other relevant details. It's built with React and uses Tailwind CSS for styling.

## Features

- **Stock Information**: Displays stock symbol, company name, current price, change, and change percentage.
- **Change Indicators**: Visually indicates whether the stock price is up (green), down (red), or neutral (gray).
- **Responsive Design**: The layout adapts to various screen sizes, using Tailwind's grid system for smaller and larger devices.
- **Interactivity**: The component is clickable (`onClick`), allowing for additional actions or navigation when the card is selected.
- **Conditional Styling**: Applies custom styles when the card is selected, highlighting the border and adding a shadow effect.
