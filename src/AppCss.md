# 🎨 Global Styles (`index.css` or `App.css`)

This CSS file defines the global styles for the application. It includes layout settings, logo effects, animations, and responsive design for accessibility.

---

## 📁 File Overview

### ✅ Key Selectors

- `#root` – Centers the main app content.
- `.logo` – Adds hover animations and spinning effect.
- `.card` – Standard card padding style.
- `.read-the-docs` – Lighter text for instructional content.
